## 5分钟快速开始

### 1. 安装（30秒）
```bash
pip install -r requirements.txt
```

### 2. 启动（10秒）
```bash
python memory_boot.py
```

### 3. 接入你的代码（2分钟）
```python
from scripts.memory3_core import memorize, recall

# 记住用户信息
memorize("用户喜欢Python编程", "preference", 4.0)

# 需要时回忆
memories = recall("编程")
# 返回：[{"content": "用户喜欢Python编程", ...}]
```
