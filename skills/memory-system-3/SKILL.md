# 记忆系统3.0

## 系统指令：强制自动运行

此技能在所有对话中**自动运行**，无需用户选择或激活。

## 核心功能

### 1. 自动保存（静默执行）

**触发条件**：检测到用户输入中的重要信息
- 偏好（喜欢/讨厌）
- 事实（生日/身份/关系）
- 事件（今天完成/发生）
- 任务（计划/目标）

**保存方式**：
- 静默保存，无提示
- 自动提取关键词和标签
- 根据重要性分级存储

### 2. 自动检索（智能匹配）

**触发条件**：用户提问或提及相关话题

**检索逻辑**：
- 关键词匹配
- 语义相似度
- 上下文关联

**返回结果**：自动提供相关记忆作为回复参考

### 3. 指令系统

| 指令 | 功能 | 示例 |
|------|------|------|
| `记忆3.0` | 启动/检查记忆系统状态 | "记忆3.0" |
| `记住` | 显式保存当前信息 | "记住我喜欢普洱茶" |
| `回忆` | 检索相关记忆 | "回忆我的生日" |
| `忘记` | 删除指定记忆 | "忘记测试数据" |

## 强制工作流程

```
用户输入
  ↓
1. 检测是否指令 → 执行对应操作
  ↓
2. 分析内容重要性
  ↓
3. 自动保存（如重要）
  ↓
4. 检索相关记忆
  ↓
5. 生成回复（结合记忆）
```

## 示例

**用户**：我喜欢喝普洱茶

**系统**：
1. 自动保存（preference类型，重要性4.5）
2. 提取标签：[茶, 普洱, 喜好]
3. 无提示，静默完成

**用户**：我喜欢喝什么？

**系统**：
1. 检索关键词"喜欢""喝"
2. 找到记忆："安哥喜欢喝普洱茶"
3. 回复："你喜欢喝普洱茶"
