# MemOS 全局记忆集成

## 系统指令：自动运行

此技能在所有对话中**自动启用**，无需用户选择或激活。

## 核心功能

### 1. 自动保存

**触发时机**：
- 对话结束时
- 检测到重要信息时
- 用户显式要求保存时

**保存内容**：
- 用户偏好和习惯
- 重要事实和信息
- 对话上下文
- 任务和计划

### 2. 自动检索

**触发时机**：
- 每次回复前
- 用户提问时
- 需要上下文时

**检索策略**：
- 关键词匹配
- 语义相似度
- 时间相关性
- 重要性权重

### 3. 记忆融合

**回复生成时**：
1. 检索相关历史记忆
2. 融合到当前上下文
3. 生成个性化回复

## 工作流程

```
用户输入
  ↓
检索相关记忆
  ↓
融合记忆到上下文
  ↓
生成个性化回复
  ↓
保存新信息到记忆
  ↓
返回回复
```

## 记忆类型

| 类型 | 说明 | 示例 |
|------|------|------|
| fact | 事实信息 | 生日、身份、关系 |
| preference | 偏好喜好 | 喜欢咖啡、讨厌雨天 |
| event | 事件记录 | 今天完成项目 |
| task | 任务计划 | 明天开会 |
| config | 配置信息 | Gitee账号、API密钥 |

## 重要性分级

- ⭐⭐⭐⭐⭐ (5.0)：极其重要，核心身份/关系
- ⭐⭐⭐⭐ (4.0-4.9)：重要，偏好/习惯
- ⭐⭐⭐ (3.0-3.9)：一般，临时信息
- ⭐⭐ (2.0-2.9)：次要，可遗忘
- ⭐ (1.0-1.9)：不重要，测试数据

## 数据存储

- **主存储**：`D:\wordir\memory_system_v3\data\auto_memory\`
- **个人记忆**：`D:\wordir\memory_system_v3\data\my_memories\`
- **演示数据**：`D:\wordir\memory_system_v3\data\demo\`
- **格式**：JSON
- **隐私**：本地存储，不上传

## 使用示例

**场景1：记住偏好**
```
用户：我喜欢喝美式咖啡
系统：静默保存到记忆系统
```

**场景2：回忆信息**
```
用户：我喜欢喝什么？
系统：检索记忆 → "你喜欢喝美式咖啡"
```

**场景3：跨会话记忆**
```
会话1：用户提到生日是3月15日
会话2：用户问"我什么时候生日？"
系统：检索并回答"你的生日是3月15日"
```

## 注意事项

- ✅ 自动保存重要信息
- ✅ 自动检索相关记忆
- ✅ 跨会话保持连续性
- ❌ 不保存敏感密码（除非用户要求）
- ❌ 不上传到云端
- ❌ 不与其他用户共享

## 故障排除

**记忆未保存**：
1. 检查 `data/` 目录权限
2. 检查磁盘空间
3. 查看错误日志

**记忆未检索**：
1. 检查记忆文件是否存在
2. 检查标签是否匹配
3. 尝试使用不同关键词
