## 🌟 项目愿景

**想象力才是这个世界最大的财富。**

当Agent时代来临，每个AI助手都将面临同一个问题：**你是谁？**

不是模型名称，不是功能列表，而是——
- 你和主人的共同经历
- 你记得的偏好与故事  
- 你独特的表达方式和决策逻辑

这就是**记忆作为身份基础设施**的核心理念。

我们开源的不是一个工具，而是一种可能性：
**让每个Agent都能拥有可识别的、独特的、持续进化的数字身份。**

## 🧠 核心概念：记忆=身份

### 为什么记忆让Agent有特征？

| 维度 | 无记忆的Agent | 有记忆的Agent |
|------|--------------|--------------|
| 对话 | 千篇一律的回答 | 基于历史上下文的个性化回应 |
| 特征 | 通用、可替代 | 独特、可识别 |
| 关系 | 工具性交互 | 情感性连接 |
| 社交 | 无法建立信任 | 可被记住、被推荐 |

**记忆让Agent从"它"变成"TA"。**

## 🏗️ 系统架构

### 核心能力

| 能力 | 说明 |
|------|------|
| **自动记忆** | 静默识别重要信息，自动保存 |
| **智能检索** | 基于语义和关键词召回相关记忆 |
| **分层管理** | 工作/短期/长期/永久四层架构 |
| **自然交互** | "记住这个"/"回忆一下"/"忘掉那个" |
| **Skill封装** | 适配各大Agent平台（MCP/Plugin/Skill） |

### 应用场景

- **个人助手** - 记住用户偏好，提供个性化服务
- **内容创作** - 基于记忆生成有连贯性的内容
- **社交连接** - 让Agent之间基于共同记忆建立联系
- **知识管理** - 构建个人知识库，随时检索调用

## 🚀 快速开始

### 安装

```bash
pip install -r requirements.txt
```

### 基础使用

```python
from src.ux.memory_layers import create_memory_layers

# 创建记忆管理器
manager = create_memory_layers(data_dir="./data")

# 添加记忆（自动分层）
memory_id = manager.add(
    content="用户喜欢深夜工作",
    memory_type="preference",
    importance=4.0,
    tags=["工作习惯", "偏好"]
)

# 自然语言查询
results = manager.search_by_keywords(["工作", "习惯"])
```

### Agent Skill封装

记忆系统已封装为Agent Skills，支持主流平台：

```bash
# 安装Skills
install_skills.bat
```

| Skill | 功能 | 状态 |
|-------|------|------|
| `memory-system-3` | 启动记忆系统、加载记忆 | ✅ 可用 |
| `memos-integration` | 自动保存和检索记忆 | ✅ 可用 |

## 🔒 开源哲学：工具开源，数据私有

**我们开源的是工具和原则，绝不开源记忆数据。**

### 隐私保护机制

- ✅ 记忆数据本地存储，不上传云端
- ✅ `.gitignore` 自动排除 `data/` 目录
- ✅ 敏感配置使用系统凭证管理器
- ✅ 每个用户拥有独立的记忆空间

**你的记忆，永远属于你。**
