## 一、设计目标

设计一套灵活、可扩展的数据同步配置格式，支持记忆系统从多种外部数据源（如新书房文档、API、数据库等）同步数据，解决记忆系统数据过时问题。

---

## 二、设计原则

### 2.1 体系化原则（PRIN-005）
- 配置格式要成体系，清晰的层级结构
- 从数据源类型 → 同步策略 → 记忆映射，层层递进

### 2.2 最小改动最大效果
- 优先支持文件类型数据源（新书房已有大量md文档）
- 配置文件使用YAML格式（人类可读，易于维护）
- 不引入复杂依赖，使用Python标准库

### 2.3 可扩展性
- 支持多种数据源类型（file/api/database）
- 支持多种同步策略（realtime/hourly/daily/weekly/manual）
- 支持自定义记忆标签和元数据

## 三、配置格式设计

### 3.1 总体结构

```yaml
# config/sync_config.yaml

# 全局配置
global:
  enabled: true                    # 是否启用同步功能
  log_level: "INFO"                # 日志级别
  sync_on_startup: true            # 启动时是否自动同步
  default_sync_interval: "daily"   # 默认同步频率

# 数据源配置列表
sync_sources:
  - name: "todo_master"              # 数据源名称（唯一标识）
    enabled: true                    # 是否启用此数据源
    type: "file"                     # 数据源类型
    source_config:                   # 数据源特定配置
      path: "D:/AnZai_JieYue/02-Plans/TODO-MASTER.md"
      encoding: "utf-8"
      watch_changes: true            # 是否监听文件变化
    sync_strategy:                   # 同步策略
      interval: "daily"              # 同步频率
      time: "00:00"                  # 同步时间（对于daily/weekly）
      on_change: true                # 文件变化时立即同步
    memory_mapping:                  # 记忆映射配置
      memory_type: "task"            # 记忆类型
      tags: ["待办事项", "总清单", "当前任务", "TODO-MASTER"]
      validity_type: "volatile"      # 时效性类型
      expires_after: "1d"            # 过期时间（1d=1天）
      supersede_old: true            # 是否替代旧记忆
      supersede_tags: ["待办事项", "总清单"]  # 替代哪些标签的旧记忆
    metadata:                        # 自定义元数据
      source: "TODO-MASTER.md"
      priority: "high"
      auto_sync: true

  - name: "personal_info"
    enabled: true
    type: "file"
    source_config:
      path: "D:/AnZai_JieYue/03-Personal/个人信息.md"
      encoding: "utf-8"
    sync_strategy:
      interval: "weekly"
      time: "Sun 00:00"              # 每周日零点
      on_change: false
    memory_mapping:
      memory_type: "fact"
      tags: ["个人信息", "用户资料", "基础数据"]
      validity_type: "long_term"     # 长期有效
      expires_after: "90d"           # 90天后过期
      supersede_old: true
      supersede_tags: ["个人信息"]
    metadata:
      source: "个人信息.md"
      priority: "medium"

  - name: "daily_notes"
    enabled: false                   # 暂不启用
    type: "directory"                # 目录类型（批量同步）
    source_config:
      path: "D:/AnZai_JieYue/01-Daily"
      pattern: "*.md"                # 文件匹配模式
      recursive: false               # 不递归子目录
      encoding: "utf-8"
    sync_strategy:
      interval: "hourly"
      on_change: true
    memory_mapping:
      memory_type: "event"
      tags: ["日记", "每日记录"]
      validity_type: "medium_term"
      expires_after: "30d"
      supersede_old: false           # 不替代，追加
    metadata:
      source: "daily_notes"
      priority: "low"
```

### 3.2 数据源类型（source_config）

#### 3.2.1 文件类型（type: "file"）
```yaml
source_config:
  path: "绝对路径/文件名.md"
  encoding: "utf-8"
  watch_changes: true              # 是否监听文件变化
```

#### 3.2.2 目录类型（type: "directory"）
```yaml
source_config:
  path: "绝对路径/目录"
  pattern: "*.md"                  # glob模式
  recursive: false                 # 是否递归
  encoding: "utf-8"
  watch_changes: true
```

#### 3.2.3 API类型（type: "api"）- 预留扩展
```yaml
source_config:
  url: "https://api.example.com/data"
  method: "GET"
  headers:
    Authorization: "Bearer ${API_TOKEN}"
  params:
    user_id: "安哥"
  response_format: "json"
  data_path: "data.items"          # JSON路径
```

#### 3.2.4 数据库类型（type: "database"）- 预留扩展
```yaml
source_config:
  connection_string: "sqlite:///path/to/db.sqlite"
  query: "SELECT * FROM tasks WHERE status='active'"
  columns:
    - name: "title"
      map_to: "content"
    - name: "tags"
      map_to: "tags"
```

### 3.3 同步策略（sync_strategy）

#### 3.3.1 同步频率（interval）
- `realtime`: 实时同步（文件监听）
- `hourly`: 每小时同步
- `daily`: 每天同步（需指定time）
- `weekly`: 每周同步（需指定time，如"Sun 00:00"）
- `manual`: 仅手动触发

#### 3.3.2 同步时间（time）
- daily: "HH:MM" 格式，如 "00:00"
- weekly: "Day HH:MM" 格式，如 "Sun 00:00"、"Mon 08:00"

#### 3.3.3 变化触发（on_change）
- `true`: 文件变化时立即同步
- `false`: 仅按interval定时同步

### 3.4 记忆映射（memory_mapping）

#### 3.4.1 时效性类型（validity_type）
```python
VALIDITY_TYPES = {
    "static": "永久有效",        # 个人信息、核心原则
    "long_term": "长期有效",     # 项目目标、战略规划（90天）
    "medium_term": "中期有效",   # 季度计划、月度总结（30天）
    "short_term": "短期有效",    # 周计划、每日任务（7天）
    "volatile": "易变数据",      # 待办清单、实时状态（1天）
}
```

#### 3.4.2 过期时间（expires_after）
- 格式: `数字 + 单位`
- 单位: `d`(天)、`h`(小时)、`w`(周)、`m`(月)
- 示例: "1d"、"12h"、"2w"、"3m"

#### 3.4.3 替代策略（supersede_old）
- `true`: 新记忆替代旧记忆（适用于待办清单）
- `false`: 新记忆追加，不替代（适用于日记）

#### 3.4.4 替代范围（supersede_tags）
- 指定哪些标签的旧记忆会被替代
- 示例: `["待办事项", "总清单"]` - 只替代同时包含这两个标签的旧记忆

## 四、数据流设计

### 4.1 同步流程

```
┌─────────────────────────────────────────────────┐
│  1. 读取配置文件（sync_config.yaml）              │
└──────────────────┬──────────────────────────────┘
                   │
┌──────────────────▼──────────────────────────────┐
│  2. 遍历所有启用的数据源                          │
│     - 检查是否到达同步时间                        │
│     - 检查文件是否有变化                          │
└──────────────────┬──────────────────────────────┘
                   │
┌──────────────────▼──────────────────────────────┐
│  3. 读取数据源内容                                │
│     - 文件: 读取文件内容                          │
│     - API: 发送HTTP请求                          │
│     - 数据库: 执行SQL查询                         │
└──────────────────┬──────────────────────────────┘
                   │
┌──────────────────▼──────────────────────────────┐
│  4. 对比现有记忆                                  │
│     - 搜索相同标签的旧记忆                        │
│     - 计算内容差异                                │
└──────────────────┬──────────────────────────────┘
                   │
┌──────────────────▼──────────────────────────────┐
│  5. 执行同步操作                                  │
│     - 如果supersede_old=true: 标记旧记忆为过时   │
│     - 创建新记忆，设置validity和expires_at        │
│     - 在新记忆metadata中记录supersedes关系        │
└──────────────────┬──────────────────────────────┘
                   │
┌──────────────────▼──────────────────────────────┐
│  6. 记录同步日志                                  │
│     - 同步时间、数据源、操作类型、结果            │
└───────────────────────────────────────────────────┘
```

## 五、实现要点

### 5.1 配置加载
```python
import yaml
from pathlib import Path

class SyncConfigLoader:
    def __init__(self, config_path="config/sync_config.yaml"):
        self.config_path = Path(config_path)
        self.config = self.load_config()
    
    def load_config(self):
        """加载配置文件"""
        if not self.config_path.exists():
            raise FileNotFoundError(f"配置文件不存在: {self.config_path}")
        
        with open(self.config_path, 'r', encoding='utf-8') as f:
            config = yaml.safe_load(f)
        
        # 验证配置格式
        self.validate_config(config)
        return config
    
    def validate_config(self, config):
        """验证配置格式"""
        # 检查必需字段
        assert 'sync_sources' in config
        for source in config['sync_sources']:
            assert 'name' in source
            assert 'type' in source
            assert 'source_config' in source
            assert 'sync_strategy' in source
            assert 'memory_mapping' in source
```

### 5.2 文件监听
```python
from watchdog.observers import Observer
from watchdog.events import FileSystemEventHandler

class FileChangeHandler(FileSystemEventHandler):
    def __init__(self, sync_service, source_name):
        self.sync_service = sync_service
        self.source_name = source_name
    
    def on_modified(self, event):
        """文件修改时触发"""
        if not event.is_directory:
            self.sync_service.sync_source(self.source_name)
```

### 5.3 时间调度
```python
from apscheduler.schedulers.background import BackgroundScheduler

class SyncScheduler:
    def __init__(self, sync_service):
        self.sync_service = sync_service
        self.scheduler = BackgroundScheduler()
    
    def schedule_source(self, source_config):
        """为数据源添加定时任务"""
        interval = source_config['sync_strategy']['interval']
        time = source_config['sync_strategy'].get('time')
        
        if interval == 'hourly':
            self.scheduler.add_job(
                self.sync_service.sync_source,
                'interval',
                hours=1,
                args=[source_config['name']]
            )
        elif interval == 'daily':
            hour, minute = time.split(':')
            self.scheduler.add_job(
                self.sync_service.sync_source,
                'cron',
                hour=hour,
                minute=minute,
                args=[source_config['name']]
            )
```

## 六、使用示例

### 6.1 基本使用
```python
from sync import DataSyncService

# 初始化同步服务
sync_service = DataSyncService(config_path="config/sync_config.yaml")

# 启动自动同步
sync_service.start()

# 手动触发同步
sync_service.sync_source("todo_master")

# 同步所有数据源
sync_service.sync_all()

# 停止同步
sync_service.stop()
```

### 6.2 集成到记忆系统
```python
from api import UnifiedAPI
from sync import DataSyncService

# 初始化
api = UnifiedAPI(data_dir="./data")
sync_service = DataSyncService(
    config_path="config/sync_config.yaml",
    memory_api=api
)

# 启动时自动同步
if sync_service.config['global']['sync_on_startup']:
    sync_service.sync_all()

# 启动后台同步
sync_service.start()
```
