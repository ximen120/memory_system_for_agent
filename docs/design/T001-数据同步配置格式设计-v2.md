### 1.1 要解决什么问题

**具体问题**：
- 用户搜索"待办事项"返回过时数据（T004-T008旧任务，而非最新的TODO-MASTER内容）

- 用户操作流程正常（启动记忆系统→搜索待办），但结果错误

## 二、设计思路与原则

### 2.1 解决思路

**核心思路**：建立"数据源 → 同步策略 → 记忆映射"的三层配置体系

1. **数据源层**：定义外部数据源（文件/目录/API/数据库）
2. **同步策略层**：定义同步频率、触发条件、冲突处理
3. **记忆映射层**：定义如何转换为记忆（类型、标签、时效性）

**同步逻辑**：
1. 读取数据源内容
2. 搜索现有记忆（通过tags匹配）
3. 如果内容变化：标记旧记忆为"过时" → 创建新记忆
4. 设置新记忆的时效性和过期时间
5. 在metadata中记录版本关系（supersedes）

### 2.2 设计原则

1. **基于现有代码集成**（原则一）：
   - 使用现有的`UnifiedAPI`接口
   - 使用现有的`MemoryUnit`数据结构
   - 扩展`metadata`字段，不修改核心结构

2. **与Roadmap集成**（原则二）：
   - 为T002 DataSyncService提供配置基础
   - 支持后续T003-T004的集成需求

3. **最小改动最大效果**（PRIN-005）：
   - 优先支持file类型（新书房已有大量md文档）
   - 使用YAML格式（人类可读，Agent易解析）
   - 不引入复杂依赖（仅PyYAML）

4. **Agent友好**（原则四）：
   - 配置结构清晰，易于解析
   - 提供完整示例
   - 错误提示明确

5. **可测试可验收**（原则五、六）：
   - 每个配置项可验证
   - 同步结果可量化

### 3.3 配置项详细说明

#### 3.3.1 数据源类型（type）

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| `file` | 单个文件 | TODO-MASTER.md、个人信息.md |
| `directory` | 目录（批量） | 过程记录、日记目录 |
| `api` | HTTP API | 外部系统数据（预留） |
| `database` | 数据库 | 结构化数据（预留） |

#### 3.3.2 同步频率（interval）

| 频率 | 说明 | 适用场景 |
|------|------|----------|
| `realtime` | 实时（文件监听） | 待办清单 |
| `hourly` | 每小时 | 过程记录 |
| `daily` | 每天（需指定time） | 个人信息 |
| `weekly` | 每周（需指定time） | 周报、总结 |
| `manual` | 仅手动触发 | 重要但不频繁的数据 |

#### 3.3.3 时效性类型（validity_type）

与现有系统的`WORK_MEMORY_HOURS`/`SHORT_TERM_DAYS`等配置对应：

| 类型 | 说明 | 默认过期时间 | 对应配置 |
|------|------|--------------|----------|
| `static` | 永久有效 | 无 | - |
| `long_term` | 长期有效 | 90天 | `LONG_TERM_DAYS` |
| `medium_term` | 中期有效 | 30天 | `MID_TERM_DAYS` |
| `short_term` | 短期有效 | 7天 | `SHORT_TERM_DAYS` |
| `volatile` | 易变数据 | 1天 | `WORK_MEMORY_HOURS` |

#### 3.3.4 冲突处理（conflict_resolution）

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| `replace` | 替代旧记忆 | 待办清单（完全替换） |
| `append` | 追加新记忆 | 日记（增量追加） |
| `skip` | 跳过 | 手动处理冲突 |

│  - 如果 supersede_old=true:                                  │

└──────────────────────┬──────────────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────────────┐
│  Step 6: 记录日志                                            │
│  - 记录同步时间、数据源、操作类型、结果                      │
│  - 如失败，记录错误信息并触发重试                            │

### Step 1: 配置加载模块（config/sync_config_loader.py）

```python
import yaml
import logging
from pathlib import Path
from typing import List, Dict, Any
from sync.exceptions import ConfigError

logger = logging.getLogger(__name__)

class SyncConfigLoader:
    """同步配置加载器"""
    
    VALID_SOURCE_TYPES = ['file', 'directory', 'api', 'database']
    VALID_INTERVALS = ['realtime', 'hourly', 'daily', 'weekly', 'manual']
    VALID_CONFLICT_RESOLUTIONS = ['replace', 'append', 'skip']
    VALID_VALIDITY_TYPES = ['static', 'long_term', 'medium_term', 'short_term', 'volatile']
    
    def __init__(self, config_path: str = "config/sync_config.yaml"):
        self.config_path = Path(config_path)
        self.config = self._load_config()
    
    def _load_config(self) -> Dict[str, Any]:
        """加载并验证配置"""
        if not self.config_path.exists():
            raise ConfigError(f"配置文件不存在: {self.config_path}")
        
        try:
            with open(self.config_path, 'r', encoding='utf-8') as f:
                config = yaml.safe_load(f)
        except yaml.YAMLError as e:
            raise ConfigError(f"YAML格式错误: {e}")
        except Exception as e:
            raise ConfigError(f"读取配置文件失败: {e}")
        
        self._validate_config(config)
        logger.info(f"成功加载配置: {self.config_path}")
        return config
    
    def _validate_config(self, config: Dict) -> None:
        """验证配置格式（使用raise而非assert）"""
        # 验证全局配置
        if 'global' not in config:
            raise ConfigError("配置缺少 'global' 字段")
        
        # 验证数据源列表
        if 'sync_sources' not in config:
            raise ConfigError("配置缺少 'sync_sources' 字段")
        
        if not isinstance(config['sync_sources'], list):
            raise ConfigError("'sync_sources' 必须是列表")
        
        # 验证每个数据源
        source_names = set()
        for idx, source in enumerate(config['sync_sources']):
            self._validate_source(source, idx, source_names)
    
    def _validate_source(self, source: Dict, idx: int, source_names: set) -> None:
        """验证单个数据源配置"""
        # 必填字段
        if 'name' not in source:
            raise ConfigError(f"数据源[{idx}]缺少必填字段 'name'")
        
        name = source['name']
        
        # 检查name唯一性
        if name in source_names:
            raise ConfigError(f"数据源名称重复: {name}")
        source_names.add(name)
        
        if 'type' not in source:
            raise ConfigError(f"数据源'{name}'缺少必填字段 'type'")
        
        if source['type'] not in self.VALID_SOURCE_TYPES:
            raise ConfigError(
                f"数据源'{name}'的type无效: {source['type']}, "
                f"有效值: {self.VALID_SOURCE_TYPES}"
            )
        
        if 'source_config' not in source:
            raise ConfigError(f"数据源'{name}'缺少必填字段 'source_config'")
        
        if 'sync_strategy' not in source:
            raise ConfigError(f"数据源'{name}'缺少必填字段 'sync_strategy'")
        
        if 'memory_mapping' not in source:
            raise ConfigError(f"数据源'{name}'缺少必填字段 'memory_mapping'")
        
        # 验证sync_strategy
        strategy = source['sync_strategy']
        if 'interval' in strategy:
            if strategy['interval'] not in self.VALID_INTERVALS:
                raise ConfigError(
                    f"数据源'{name}'的interval无效: {strategy['interval']}, "
                    f"有效值: {self.VALID_INTERVALS}"
                )
        
        if 'conflict_resolution' in strategy:
            if strategy['conflict_resolution'] not in self.VALID_CONFLICT_RESOLUTIONS:
                raise ConfigError(
                    f"数据源'{name}'的conflict_resolution无效: {strategy['conflict_resolution']}, "
                    f"有效值: {self.VALID_CONFLICT_RESOLUTIONS}"
                )
        
        # 验证memory_mapping
        mapping = source['memory_mapping']
        if 'validity_type' in mapping:
            if mapping['validity_type'] not in self.VALID_VALIDITY_TYPES:
                raise ConfigError(
                    f"数据源'{name}'的validity_type无效: {mapping['validity_type']}, "
                    f"有效值: {self.VALID_VALIDITY_TYPES}"
                )
    
    def get_enabled_sources(self) -> List[Dict]:
        """获取启用的数据源"""
        if not self.config['global'].get('enabled', True):
            logger.info("全局同步已禁用")
            return []
        
        enabled = [s for s in self.config['sync_sources'] if s.get('enabled', True)]
        logger.info(f"找到 {len(enabled)} 个启用的数据源")
        return enabled
    
    def get_source(self, name: str) -> Dict[str, Any]:
        """根据名称获取数据源配置"""
        for source in self.config['sync_sources']:
            if source['name'] == name:
                return source
        raise ConfigError(f"数据源不存在: {name}")
```

# sync/readers/base_reader.py
from abc import ABC, abstractmethod
from typing import Dict
import logging

logger = logging.getLogger(__name__)

class BaseReader(ABC):
    """数据源读取器基类"""
    
    @abstractmethod
    def read(self, source_config: Dict) -> str:
        """
        读取数据源内容
        
        Args:
            source_config: 数据源配置
        
        Returns:
            str: 数据源内容
        
        Raises:
            SourceNotFoundError: 数据源不存在
            SourceReadError: 读取失败
        """
        pass
    
    @abstractmethod
    def get_hash(self, source_config: Dict) -> str:
        """
        获取内容哈希（用于变化检测）
        
        Args:
            source_config: 数据源配置
        
        Returns:
            str: 内容的MD5哈希值
        """
        pass
    
    @abstractmethod
    def exists(self, source_config: Dict) -> bool:
        """
        检查数据源是否存在
        
        Args:
            source_config: 数据源配置
        
        Returns:
            bool: 是否存在
        """
        pass

# sync/readers/file_reader.py
import hashlib
import logging
from pathlib import Path
from typing import Dict
from sync.exceptions import SourceNotFoundError, SourceReadError
from .base_reader import BaseReader

logger = logging.getLogger(__name__)

class FileReader(BaseReader):
    """文件读取器"""
    
    def exists(self, source_config: Dict) -> bool:
        """检查文件是否存在"""
        path = Path(source_config['path'])
        return path.exists() and path.is_file()
    
    def read(self, source_config: Dict) -> str:
        """读取文件内容"""
        path = Path(source_config['path'])
        
        # 检查文件存在性
        if not path.exists():
            raise SourceNotFoundError(f"文件不存在: {path}")
        
        if not path.is_file():
            raise SourceNotFoundError(f"路径不是文件: {path}")
        
        # 读取文件
        try:
            encoding = source_config.get('encoding', 'utf-8')
            with open(path, 'r', encoding=encoding) as f:
                content = f.read()
            logger.debug(f"成功读取文件: {path}, 大小: {len(content)} 字符")
            return content
        except UnicodeDecodeError as e:
            raise SourceReadError(f"文件编码错误: {path}, 尝试使用 {encoding} 编码, 错误: {e}")
        except PermissionError as e:
            raise SourceReadError(f"文件权限不足: {path}, 错误: {e}")
        except Exception as e:
            raise SourceReadError(f"读取文件失败: {path}, 错误: {e}")
    
    def get_hash(self, source_config: Dict) -> str:
        """获取文件内容哈希"""
        try:
            content = self.read(source_config)
            # 规范化内容：去除首尾空白，统一换行符
            normalized = content.strip().replace('\r\n', '\n')
            hash_value = hashlib.md5(normalized.encode()).hexdigest()
            logger.debug(f"文件哈希: {hash_value}")
            return hash_value
        except Exception as e:
            logger.error(f"计算哈希失败: {e}")
            raise

### Step 3: 同步服务（sync/sync_service.py）

```python
import logging
from threading import Lock
from datetime import datetime, timedelta
from typing import List, Dict, Optional
from api import UnifiedAPI
from config.sync_config_loader import SyncConfigLoader
from sync.readers.file_reader import FileReader
from sync.readers.directory_reader import DirectoryReader
from sync.exceptions import SyncError, SourceNotFoundError

logger = logging.getLogger(__name__)

class DataSyncService:
    """
    数据同步服务
    
    负责从外部数据源同步数据到记忆系统。
    支持文件、目录、API等多种数据源类型。
    """
    
    def __init__(
        self, 
        config_path: str = "config/sync_config.yaml", 
        memory_api: Optional[UnifiedAPI] = None
    ):
        """
        初始化同步服务
        
        Args:
            config_path: 配置文件路径
            memory_api: 记忆系统API实例（可选，默认创建新实例）
        """
        self.config_loader = SyncConfigLoader(config_path)
        self.memory_api = memory_api or UnifiedAPI()
        
        # 数据源读取器
        self.readers = {
            'file': FileReader(),
            'directory': DirectoryReader(),
            # 'api': APIReader(),  # 预留
            # 'database': DatabaseReader(),  # 预留
        }
        
        # 并发控制：每个数据源一个锁
        self._locks: Dict[str, Lock] = {}
        
        # 同步历史记录（用于变化检测）
        self._sync_history: Dict[str, Dict] = {}
        
        logger.info("数据同步服务初始化完成")
    
    def sync_source(self, source_name: str) -> bool:
        """
        同步单个数据源
        
        Args:
            source_name: 数据源名称（来自配置文件的name字段）
        
        Returns:
            bool: True表示成功，False表示失败（但不会抛出异常）
        
        Raises:
            ConfigError: 配置错误
            SourceNotFoundError: 数据源不存在
            SyncError: 其他同步错误
        """
        # 获取锁
        if source_name not in self._locks:
            self._locks[source_name] = Lock()
        
        with self._locks[source_name]:
            try:
                logger.info(f"开始同步数据源: {source_name}")
                
                # 获取数据源配置
                source = self.config_loader.get_source(source_name)
                
                # 检查是否启用
                if not source.get('enabled', True):
                    logger.info(f"数据源已禁用: {source_name}")
                    return False
                
                # 获取读取器
                reader = self.readers.get(source['type'])
                if not reader:
                    raise SyncError(f"不支持的数据源类型: {source['type']}")
                
                # 检查数据源是否存在
                if not reader.exists(source['source_config']):
                    raise SourceNotFoundError(
                        f"数据源不存在: {source['source_config'].get('path', 'unknown')}"
                    )
                
                # 检查是否有变化
                current_hash = reader.get_hash(source['source_config'])
                last_hash = self._sync_history.get(source_name, {}).get('hash')
                
                if current_hash == last_hash:
                    logger.info(f"数据源无变化，跳过同步: {source_name}")
                    return True
                
                # 读取内容
                content = reader.read(source['source_config'])
                
                # 搜索现有记忆
                existing = self._find_existing_memories(source)
                
                # 执行同步策略
                conflict_resolution = source['sync_strategy'].get('conflict_resolution', 'replace')
                
                if conflict_resolution == 'replace':
                    # 标记旧记忆为过时
                    if source['memory_mapping'].get('supersede_old', True) and existing:
                        self._mark_outdated(existing, source_name)
                    
                    # 创建新记忆
                    memory_id = self._create_memory(content, source, existing)
                    logger.info(f"同步成功: {source_name}, 创建记忆: {memory_id}")
                
                elif conflict_resolution == 'append':
                    # 追加模式：直接创建新记忆，不替代旧的
                    memory_id = self._create_memory(content, source, [])
                    logger.info(f"追加成功: {source_name}, 创建记忆: {memory_id}")
                
                elif conflict_resolution == 'skip':
                    # 跳过模式：如果有现有记忆，不做任何操作
                    if existing:
                        logger.info(f"跳过同步（已有记忆）: {source_name}")
                        return True
                    memory_id = self._create_memory(content, source, [])
                    logger.info(f"同步成功: {source_name}, 创建记忆: {memory_id}")
                
                # 更新同步历史
                self._sync_history[source_name] = {
                    'hash': current_hash,
                    'last_sync': datetime.now().isoformat(),
                    'memory_id': memory_id
                }
                
                return True
                
            except SourceNotFoundError as e:
                logger.error(f"数据源不存在: {source_name}, 错误: {e}")
                raise
            except SyncError as e:
                logger.error(f"同步失败: {source_name}, 错误: {e}")
                raise
            except Exception as e:
                logger.error(f"同步异常: {source_name}, 错误: {e}", exc_info=True)
                raise SyncError(f"同步异常: {e}") from e
    
    def sync_all(self) -> Dict[str, bool]:
        """
        同步所有启用的数据源
        
        Returns:
            Dict[str, bool]: 每个数据源的同步结果
        """
        logger.info("开始同步所有数据源")
        results = {}
        
        for source in self.config_loader.get_enabled_sources():
            source_name = source['name']
            try:
                results[source_name] = self.sync_source(source_name)
            except Exception as e:
                logger.error(f"同步失败: {source_name}, 错误: {e}")
                results[source_name] = False
        
        success_count = sum(1 for v in results.values() if v)
        logger.info(f"同步完成: 成功 {success_count}/{len(results)}")
        return results
    
    def _find_existing_memories(self, source: Dict) -> List[Dict]:
        """查找现有记忆"""
        supersede_tags = source['memory_mapping'].get('supersede_tags', [])
        if not supersede_tags:
            return []
        
        try:
            # 使用现有API搜索
            results = self.memory_api.search(
                query=" ".join(supersede_tags),
                top_k=20
            )
            # 过滤：必须包含所有supersede_tags
            filtered = [
                r for r in results 
                if all(tag in r.tags for tag in supersede_tags)
                and not r.metadata.get('is_outdated', False)  # 排除已过时的
            ]
            logger.debug(f"找到 {len(filtered)} 条现有记忆")
            return filtered
        except Exception as e:
            logger.error(f"搜索现有记忆失败: {e}")
            return []
    
    def _mark_outdated(self, memories: List[Dict], new_source: str):
        """标记旧记忆为过时"""
        for mem in memories:
            try:
                # 添加过时标签
                new_tags = list(set(mem.tags + ['过时']))
                
                # 更新metadata
                new_metadata = mem.metadata.copy() if hasattr(mem, 'metadata') else {}
                new_metadata['is_outdated'] = True
                new_metadata['outdated_reason'] = f"被 {new_source} 的新版本替代"
                new_metadata['outdated_at'] = datetime.now().isoformat()
                
                self.memory_api.update_memory(
                    memory_id=mem.memory_id,
                    tags=new_tags,
                    metadata=new_metadata
                )
                logger.debug(f"标记为过时: {mem.memory_id}")
            except Exception as e:
                logger.error(f"标记过时失败: {mem.memory_id}, 错误: {e}")
    
    def _create_memory(self, content: str, source: Dict, old_memories: List[Dict]) -> str:
        """创建新记忆"""
        mapping = source['memory_mapping']
        
        # 计算过期时间
        expires_at = self._calculate_expires_at(mapping.get('expires_after', '30d'))
        
        # 构建metadata
        metadata = {
            'sync_source_name': source['name'],
            'sync_source_type': source['type'],
            'sync_source_path': source['source_config'].get('path'),
            'sync_time': datetime.now().isoformat(),
            'validity_type': mapping.get('validity_type', 'medium_term'),
            'expires_at': expires_at,
            'is_outdated': False,
        }
        
        # 记录替代关系
        if old_memories:
            metadata['supersedes'] = [m.memory_id for m in old_memories]
        
        # 合并自定义metadata
        metadata.update(source.get('metadata', {}))
        
        # 创建记忆
        try:
            memory_id = self.memory_api.remember(
                content=content,
                memory_type=mapping.get('memory_type', 'fact'),
                importance=mapping.get('importance', 3.0),
                tags=mapping.get('tags', []),
                **metadata
            )
            return memory_id
        except Exception as e:
            logger.error(f"创建记忆失败: {e}")
            raise SyncError(f"创建记忆失败: {e}") from e
    
    def _calculate_expires_at(self, expires_after: str) -> str:
        """
        计算过期时间
        
        Args:
            expires_after: 过期时间字符串，如 "1d", "7d", "30d", "12h"
        
        Returns:
            str: ISO 8601格式的过期时间
        """
        try:
            # 解析时间字符串
            unit = expires_after[-1]  # 'd', 'h', 'w', 'm'
            value = int(expires_after[:-1])
            
            now = datetime.now()
            
            if unit == 'd':  # 天
                expires = now + timedelta(days=value)
            elif unit == 'h':  # 小时
                expires = now + timedelta(hours=value)
            elif unit == 'w':  # 周
                expires = now + timedelta(weeks=value)
            elif unit == 'm':  # 月（按30天计算）
                expires = now + timedelta(days=value * 30)
            else:
                logger.warning(f"未知的时间单位: {unit}, 默认使用30天")
                expires = now + timedelta(days=30)
            
            return expires.isoformat()
        except Exception as e:
            logger.error(f"计算过期时间失败: {expires_after}, 错误: {e}")
            # 默认30天
            return (datetime.now() + timedelta(days=30)).isoformat()
```

## 七、边界情况与错误处理（新增）

### 7.1 边界情况处理

| 场景 | 处理方式 | 日志级别 |
|------|----------|----------|
| 数据源文件被删除 | 抛出SourceNotFoundError，不影响其他数据源同步 | ERROR |
| 同步过程中文件被修改 | 使用文件锁或读取时快照，保证一致性 | WARNING |
| 记忆系统数据被手动删除 | 下次同步时重新创建记忆 | INFO |
| 配置文件格式错误 | 抛出ConfigError，提供详细错误信息 | ERROR |
| 配置文件被删除 | 抛出ConfigError，服务停止 | CRITICAL |
| 网络不可用（API类型） | 重试3次，间隔指数退避（1s/2s/4s） | WARNING |
| 内存不足 | 捕获MemoryError，记录日志 | CRITICAL |
| 文件编码错误 | 抛出SourceReadError，提示正确编码 | ERROR |
| 空文件 | 跳过同步，记录WARNING | WARNING |
| 超大文件（>10MB） | 记录WARNING，仍然同步 | WARNING |

### 7.2 错误处理流程

```
┌─────────────────────────────────────────────────┐
│  同步操作                                        │
└──────────────────┬──────────────────────────────┘
                   │
                   ▼
            ┌──────────────┐
            │  操作成功？    │
            └──┬───────┬───┘
               │       │
              YES      NO
               │       │
               ▼       ▼
          ┌────────┐ ┌─────────────────────────┐
          │ 记录日志│ │ 判断错误类型             │
          │ (INFO) │ │                         │
          └────────┘ │ ConfigError → 停止服务   │
                     │ SourceNotFound → 跳过    │
                     │ SourceReadError → 重试   │
                     │ SyncError → 记录+跳过    │
                     │ 其他 → 记录+跳过         │
                     └─────────────────────────┘
```

### 7.3 日志规范

**日志格式**：
```python
# 日志配置
logging.basicConfig(
    format='%(asctime)s [%(levelname)s] %(name)s: %(message)s',
    datefmt='%Y-%m-%d %H:%M:%S'
)
```

**日志级别使用规范**：
| 级别 | 使用场景 | 示例 |
|------|----------|------|
| DEBUG | 详细调试信息 | `读取文件: /path/to/file, 大小: 1234 字符` |
| INFO | 正常操作记录 | `同步成功: todo_master, 创建记忆: mem_xxx` |
| WARNING | 非致命异常 | `数据源无变化，跳过同步: todo_master` |
| ERROR | 操作失败 | `同步失败: todo_master, 错误: 文件不存在` |
| CRITICAL | 服务级故障 | `配置文件不存在，同步服务停止` |
