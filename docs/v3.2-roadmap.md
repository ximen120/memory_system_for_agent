## 一、核心问题

### 1.1 症状
- 搜索"待办事项"返回过时数据（T004-T008等旧任务）

### 1.2 根源
- **设计假设错误**: 假设"记忆是累积不变的"
- **现实矛盾**: 很多信息是"易变有时效"的
- **缺失机制**: 没有数据同步、记忆更新、过期管理

### 🟡 P1: 检索逻辑优化

#### 2.6 智能检索
```python
class SmartRetriever:
    """智能检索器"""
    
    def search(self, query, **kwargs):
        """智能搜索"""
        # 1. 先搜索记忆系统
        memory_results = self.vector_search(query)
        
        # 2. 检查是否有同步源匹配
        sync_source = self.find_sync_source(query)
        if sync_source:
            # 检查同步源是否有更新
            if self.is_source_updated(sync_source):
                # 触发同步
                self.sync_service.sync_from_file(sync_source)
        
        # 3. 过滤过期记忆
        memory_results = self.filter_expired(memory_results)
        
        # 4. 优先返回最新记忆
        memory_results = self.prioritize_latest(memory_results)
        
        return memory_results
```
